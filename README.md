## 🚀 Projects

### [PR Review Dashboard](https://pr-dashboard-puce.vercel.app) &nbsp;🔨 *actively expanding*

> *"Finally, a dashboard that tells you who's been sitting on that PR for 3 days."*

A GitHub-connected analytics dashboard for engineering teams — and an ongoing project I'm continuously building on. Currently it surfaces cycle time, review lag, reviewer load, stale PRs, and a **Repo Health Score (0–100)**. More features are in the works.

- PR Timeline (Gantt-style), Activity Heatmap, PR Size Distribution
- Works on any public GitHub repo via OAuth 2.0 — read-only, non-invasive
- **Currently working on:** deeper analytics, private repo support, and team-level insights
- **Stack:** React · Tailwind CSS · Recharts · Zustand · GitHub OAuth 2.0 · Vite · Vercel
